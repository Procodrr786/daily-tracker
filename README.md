# Daily Discipline & Calendar Tracker

A hand-drawn, minimal personal consistency and calendar tracker built with React.js, Vite, CSS3, and Browser LocalStorage.

## Project Structure

```text
src/
├── components/
│   ├── TargetSetup.jsx
│   ├── TrackerDashboard.jsx
│   ├── CalendarGrid.jsx
│   ├── DayBox.jsx
│   ├── ProgressBar.jsx
│   └── Motivation.jsx
├── utils/
│   ├── dateUtils.js
│   └── storageUtils.js
├── App.jsx
├── App.css
└── main.jsx
```

## How to Install and Run Locally

1. **Extract the project archive** and navigate into the project directory:
   ```bash
   cd daily-discipline-tracker
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the Vite development server**:
   ```bash
   npm run dev
   ```

4. **Open in your browser**:
   Visit the local URL shown in your terminal (typically `http://localhost:5173`).
